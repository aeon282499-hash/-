## 中身
- `bb_engine.Data` を継承し、**線とシグナルだけ差し替え**。約定（次足始値＋不利1tick・往復0.10%）、1銘柄1日1玉、土俵 U0〜U7、決算除外、出口、前半/後半分割は BB と完全に同じ。
- パラメータ: 標準 9-26-52 と 半分 5-13-26（grid の `period` 列＝転換線の本数、`sigma` は 0 固定）。
- 線は銘柄ごとに**日をまたいで連続計算**（15分足の雲は約3.4日分の足が必要。最初の数日は雲なし＝玉なし）。
- シグナル6種（好転側。逆転は鏡写し。全部「終値が基準線のシグナル側」を条件に含む）:
  S1 雲抜け／S2 転換線×基準線 好転／S3 S2かつ雲上／S4 三役好転（転換>基準・雲上・遅行>26本前）／S5 基準線抜け／S6 雲上の状態（≒固定時刻・比較用）
- 出口の読み替え: 「MA回帰」= 終値が基準線の反対側へ戻った次足、「反対バンド」= 雲の反対側（好転なら雲下限割れ）、N6/N12本、引け、各 SL1% 付き など BB と同じ12種。
- 向き: band=upper が好転サイン、lower が逆転サイン。表の「順張り買い(上抜け→買)」= 好転で買い、「逆張り売り(上抜け→売)」= 好転で売り（読み替え）。
- 表の「BB」列は「転換線本数/0σ」、「乖離」列はシグナル定義。「素直な形」節は BB 専用なので空になる。

## 見るべき点（BBの結論との比較）
BB は「全銘柄では全部負け・GU売り土俵（U3/U4×10:00〜の逆張り売り）でだけ勝つが、σを使わない入口でも同じ」だった。
一目でも生き残りが U3/U4 の売りに偏るなら同じ現象（土俵が本体）。**U0/U1/U2（土俵なし）で z>2・上3日除外プラスが出るか**が一目固有の価値の判定基準。
